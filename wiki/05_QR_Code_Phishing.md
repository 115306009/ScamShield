# QR Code 釣魚（Quishing）

- 專案：ScamShield 網路詐騙辨識教學
- 分類：QR Code 釣魚（Quishing）
- 原始來源：臺灣數位發展部資通安全署
- 來源網址：https://web.moda.gov.tw/ACS/press/report/20178
- 整理日期：2026-11-17
- 資料類型：官方資料之繁體中文教學摘要（非逐字轉載）

## 核心知識

Quishing 是將釣魚網址藏在 QR Code 中，誘使使用者掃描後進入假網站。QR Code 只是連結的載體，本身不保證目的地安全。

常見情境：公共場所的 QR Code 被其他貼紙覆蓋；假冒繳費、帳號驗證或活動報名通知。

防範方法：掃描前檢查實體條碼是否有被覆蓋或改貼的痕跡；掃描後先查看網址預覽與網域拼字，不要立即開啟；若要求輸入信用卡或個資，應透過官方管道查證。

提醒：即使網址看起來正常，也應確認來源與要求的操作是否合理。

## Wiki 檢索測試

問題：掃描 QR Code 後，為什麼要先看網址預覽？

預期答案：QR Code 可能隱藏釣魚網址，先核對網域與來源可降低風險。
